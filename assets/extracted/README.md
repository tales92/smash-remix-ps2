# Área de trabalho para dados extraídos

Reservada a extrações temporárias feitas durante builds em nuvem ou preparação de assets.

- Não adicione assets extraídos ao Git.
- Não publique arquivos de ROM ou pacotes de dados protegidos como artifacts.
- Prefira diretórios temporários do runner e apague dados sensíveis ao final do job.
- Registre apenas relatórios, metadados e hashes necessários à reprodução.
