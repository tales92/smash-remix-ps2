# Área reservada para ROMs de entrada

Este diretório é um ponto de organização do projeto, não uma confirmação de que os arquivos já estão disponíveis ao GitHub Actions.

Arquivos citados pelos projetos:
- `baserom.remix.z64`: Smash Remix 2.0.1, conforme `docs/ROMAS_E_DADOS.md`.
- `baserom.us.z64`: Super Smash Bros. 64 NTSC-U v1.0.
- Para o pipeline +EXTRA, o README upstream usa `smashremix/roms/ssb.rom`; o local correto deve ser validado no submódulo e scripts.

**Não faça commit de ROMs neste diretório.** O método privado de transferência para runners ainda será escolhido. Não envie ROMs nesta pasta pelo GitHub Web sem antes definirmos armazenamento, limites e segurança.

Mantenha aqui apenas este README e arquivos de documentação sem conteúdo de ROM.
